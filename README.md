<h1>Kassa product</h1>

Kassa product — автоматизированная система, предназначенная для анализа, хранения и учёта букмекерских ставок. 

<h2>Использование</h2>

Для правильного использования обязательно прочтите файл "Инструкция.docx". Программу можно скачать в релизах (Releases): https://github.com/emelyagr/Kassa-product/releases/tag/v1.0.0
